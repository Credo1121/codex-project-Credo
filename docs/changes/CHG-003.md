# CHG-003: Screenshot-Neuaufnahme
Nutzer meldet nicht sichtbare Bilder und beauftragt erneute saubere Aufnahme. Acht echte Chromium-Screenshots der laufenden Anwendung erstellt, zusätzlich eigenständige HTML-Datei mit eingebetteten PNG-Daten, Druck-PDF und ZIP. Keine Anwendung oder Projektdaten geändert. Reproduzierbarer Befehl: node scripts/recapture.mjs, benötigt ignorierte QA-Umgebung. Aufnahmezeitpunkte, Viewports und PNG-Prüfsummen im recapture/manifest.json. Desktop-/Mobile-Übersicht, Intervieworganisation und Fragenbereich visuell geprüft. Die Darstellung lokaler Dateilinks beim Nutzer bleibt unbestätigt; neue Bilddateien allein beheben keinen Fehler des Chat-Clients.
