# CHG-006 – Frontend-Vorschau für GitHub Pages

Auftrag: Nutzer möchte zuerst das Frontend ohne Backend auf seiner Pages-Adresse durchklicken. Eigener statischer Next-Export in pages-preview erhält die vollständige Anwendung. Workspace-Prop preview aktiviert isolierten Browserdatenadapter; Standardmodus nutzt weiterhin die authentifizierte API. Keine Backendänderung. Synthetisches Projekt und Sitzung initialisiert; Vorschauhinweis/Reset sichtbar. Keine behauptete Login-Sicherheit oder serverseitige Speicherung der Demo. basePath /codex-project-Credo entspricht der Zieladresse.

Akzeptanz: statischer Build ohne Secrets oder Node-Laufzeit; Übersicht, Roadmap, Aufgaben und Leitfaden nutzbar; Browserpersistenz/Reset; ausgewählte Fragen druckbar; keine API-Aufrufe im Vorschauablauf; responsive Ansichten. Nutzerauthorisierung: Frontend-Reduktion zum Look-and-Feel-Test und Veröffentlichung über Pages; Push bestehend autorisiert.

Prüfung (8. Oktober 2026): pages:build PASS; Typecheck PASS; lint PASS mit drei bestehenden Navigationswarnungen. Anfangs CSS-Importpfad falsch, korrigiert; anfänglicher Lint erfasste generierte verschachtelte Next-Ausgabe, globale Ignorepfade ergänzt, erneut bestanden. qa:build der vollständigen App PASS. Tatsächlicher statischer HTTP-Server auf 3020 unter Projekt-Subpfad und Chromium-Test scripts/check-pages.mjs PASS: Übersicht, mobile Breite, Checkliste, angepasste/ausgewählte Fragen, Speichern/Neuladen, acht Fragen in Druckansicht, Reset, Projektanlage; keine Browserfehler/API-Requests. Export auf genaue konfigurierte Secretwerte geprüft: keine Treffer.
