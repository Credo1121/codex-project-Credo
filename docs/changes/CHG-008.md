# CHG-008 – einzelne Branch-Veröffentlichung und Versionsnachweis

Nutzer bestätigt Deploy from a branch, main, root und grünen Lauf; sieht weiter Anleitung. Remote-main mit explizitem Fetch aktualisiert und geprüft: 71269f4, index.html und statische App vorhanden. Lokales origin/main war aufgrund Fetch-Refspec nur für origin/HEAD veraltet; kein Beleg für fehlenden Push. Öffentlicher HTTPS-/API-Zugriff bleibt 403; konkrete Live-Ursache unverifiziert.

Konfiguration an bestätigten Betriebsweg angeglichen: zusätzlicher Actions-Deploy entfernt, eigener Workflow führt ausschließlich npm ci/lint/pages:build aus. Native Branch-Pages-Veröffentlichung bleibt zuständig. pages-version.json mit CHG-008 markiert die Auslieferung unabhängig vom App-/Browsercache. PAGES.md nennt zuständigen Lauf und Prüf-URL. Keine UI-/Daten-/Authänderung; bestehende statische Browserprüfung und Screenshots aus CHG-006/007 gelten für unveränderte App.

Prüfung: JSON-Marker und Git-Diff geprüft. Statischer App-Export unverändert zu 71269f4. Neue Action-Validierung entspricht bereits erfolgreich ausgeführten Befehlen; tatsächlicher Actions-Lauf/Live-Seite NOT RUN mangels API-/HTTP-Zugriff. Nach Push Zieladresse mit Release-Query und Versionsdatei vom Nutzer prüfen. Keine Live-Bereitschaft behauptet. Rücknahme: Workflow und Marker auf vorigen Commit zurücksetzen, Branch erneut veröffentlichen.
