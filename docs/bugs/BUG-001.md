# BUG-001: Login-Request im Produktionsserver
REQ-001 AC-02; hoch, Kernreise verhindert. Produktionsstart Next 16.4/Node 24; HTTP Login verursachte private Request-State-TypeError statt Authantwort.
Hypothese: Next Requestwrapper lässt sich nach Bodyread nicht über new Request(request) klonen. Fixversuch 1: native Request aus URL, Methode, Headers und Body rekonstruieren. Erwartung: Better Auth erhält einen unverbrauchten nativen Request. Regression: komplette Browserreise. Ergebnis nach Rerun dokumentieren. Keine Zugangsdaten in Bericht.

Status: behoben und durch die vollständige Browserreise verifiziert (2 Tests bestanden im letzten vollständigen Lauf).
