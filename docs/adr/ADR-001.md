# ADR-001: integrierter lokaler Workspace
Status: beschlossen innerhalb der autorisierten Architekturarbeit; 2026-10-08.
Kontext: Einzel-Admin, zunächst lokal, dauerhaft, Next.js/Node vorgegeben.
Optionen: SQLite oder PostgreSQL; Better Auth oder eigene Authentwicklung.
Entscheidung: Next.js App Router, SQLite/better-sqlite3, Better Auth; keine eigene Kryptografie. Schema via Zod, SQL-Revisionen, isolierte Browserprüfung.
Folgen: einfacher lokaler Start; native SQLite-Abhängigkeit, ein Serverprozess und beschränkte Schreiblast. Keine Serverless-Kompatibilität zugesagt. PostgreSQL bei späterer Zusammenarbeit/Hosting neu bewerten. Migrationen und Backup separat versionieren; App-Rollback stellt Daten nicht zurück.
